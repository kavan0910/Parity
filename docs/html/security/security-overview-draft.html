DRAFT. Not approved for publication. Every statement must be re-verified against the running product by the owner first. Items in brackets are decisions or facts not yet established. We do not claim certifications.

What this service does with your code

migration-agent reads your repository to build an evidence-backed understanding document. It never executes your code. Analysis happens in an isolated worker; excerpts of your code are sent to an AI model provider to produce the analysis (see "AI model provider").

Isolation

  • Each workspace's data is separated by access controls in the application and database. Resources of other workspaces are indistinguishable from nonexistent ones.
  • Analysis runs in a hardened container: non-root, read-only filesystem, no extra privileges, resource limits, no code execution of your repository.
  • The analysis container can reach only the model provider's endpoint, through an allowlisting proxy. [Planned: one-time-use container per analysis run; not yet implemented.]

Secrets in your repository

Known credential files are withheld and common secret patterns are redacted before analysis. Redaction is pattern based and best effort; unusual secrets can be missed. Please rotate any secret you suspect was exposed.
